# Big-unlucky-wheel
This is a simple interactive prize wheel program written in Python. The user can spin the wheel by typing "YES" and will randomly receive a prize from a predefined list. The program also handles invalid inputs with funny messages, making it more engaging.

Perfect for beginners to practice Python basics like:
input() and user interaction
Conditional statements (if, elif, else)
Lists and random selection (random.choice)
Basic string manipulation


How to Use????:

1.Run the Python script.

2.Follow the prompt and type YES to spin the wheel.

3.The program will display your prize

a humorous message will appear if you type anything else
